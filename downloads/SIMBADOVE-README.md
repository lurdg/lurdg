# SIMBA DOVE GLOBAL LOGISTICS 1.0.7

For existing 1.0.5/1.0.6 sites use [the small update](simbadove-update-1.0.7.zip) and [its installation guide](simbadove-update-1.0.7-guide.md).

Buttons are styled and grouped. Public tracking displays approved sender/receiver names and postal addresses, shipment type, weight and package count. Dedicated phone/email fields and internal information remain private. No database migration or config changes.

[simbadove-global-logistics.zip](simbadove-global-logistics.zip) is the complete source for fresh installations; follow the installation guide inside it. Do not overwrite production configuration with a fresh installation.
