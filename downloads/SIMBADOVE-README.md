# Simba Dove Global Logistics — 1.0.0

Download simbadove-global-logistics.zip and start with INSTALLATION.md inside it.
Separate migration and installation guides are also provided here.

Includes PHP/MySQL website, customer portal, role-based administration, shipment tracking, documents, SMTP notifications, reports and migration utilities. Bundled dependencies; no Composer or SSH required on Namecheap.

The original WordPress installation has not been changed. Actual business data migration requires authorized exports and reconciliation. Unverified historical/accreditation/statistics claims remain unpublished. No live GPS/carrier integration, antivirus scanning or in-app MFA is claimed.

Validated locally on PHP 8.4/MariaDB with functional/security checks, 40 browser viewport combinations, authenticated STARTTLS SMTP, Apache routing and a 26-table backup/restore. Run host preflight and production acceptance checks before cutover.
